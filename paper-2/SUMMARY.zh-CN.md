# 第二篇论文草稿：中文白话摘要与边界

## 一句话结论

这篇草稿严格证明了一件**有条件的否定结果**：在三维整数速度网格

`V_m={-m,…,m}^3`

上，如果每个速度点参加的弹性矩形数始终有统一上界，而且每个矩形的两条边长度也始终有统一上界，那么按顶点度数规范化后的商空间谱隙最多是 `O(m^-2)`，一定趋于零。因此，固定尺度的局部矩形拼接、固定小块粘合，不能给出统一谱隙的稀疏扩张器。

这**不**排除边长随 `m` 增长的非局部矩形构造。无约束的非局部命题仍然是开放问题。

## 模型是什么

一个弹性矩形可写成四个速度点

`a, a+p, a+q, a+p+q`，其中 `p·q=0`。

它对函数 `f` 给出一行约束

`Δf=f(a)+f(a+p+q)-f(a+p)-f(a+q)`。

这些行自动消掉五个碰撞不变量：

`1, x, y, z, x^2+y^2+z^2`。

把所有行组成矩阵 `C_m`，令 `d_v` 为顶点 `v` 参加的矩形数，`D_m=diag(d_v)`，本文采用的规范化矩阵是

`A_m=(1/2) C_m D_m^{-1/2}`。

谱隙 `γ_m` 是在去掉加权后的五维不变量空间 `D_m^{1/2}K_m` 后，`A_m` 的最小奇异值。本文始终要求每个顶点的度数为正；孤立点会破坏这个规范化，也会带来额外自由方向。

## 严格定理 `[R]`

若对所有顶点都有

`1 <= d_v <= D`，

并且每个矩形都能选择边向量 `p,q` 满足

`|p| <= L, |q| <= L`，

那么

`γ_m <= (L^2/2) sqrt(D(2m+1)^3/G_m)`，

其中

`G_m=sum_{v∈V_m}(x^2-y^2)^2`

并且

`G_m = 2S_0(S_0S_4-S_2^2)`，

`S_j=sum_{t=-m}^m t^j`。

把有限和化简后得到

`G_m = 2(2m+1)^3 m(m+1)(4m^2+4m-3)/45`，

所以

`γ_m <= L^2 sqrt(45D/32) m^-2 (1+o(1))`。

### 证明的核心想法

取测试函数

`g(x,y,z)=x^2-y^2`。

由于立方网格关于交换 `x,y` 和坐标变号都是对称的，`g` 与五个已知不变量正交。再把 `g` 按顶点度数作加权投影，减去它在五维不变量空间中的部分，得到一个合法的商空间测试向量。

对一个矩形直接展开可得

`Δg=2(p_x q_x-p_y q_y)`，

因此 `|Δg|<=2L^2`。另一方面，每行碰到四个顶点，所以

`4|R_m|=sum_v d_v<=D|V_m|`。

分子由这两个估计控制；分母则至少为 `G_m`。代入 Rayleigh 商就得到上面的显式上界。

## 这个定理准确排除了什么

它排除的是同时满足以下条件的无限族：

1. 每个顶点度数有统一常数上界；
2. 每个顶点度数为正；
3. 所有矩形边长有统一常数上界；
4. 使用本文的度数规范化 `A_m=(1/2)C_mD_m^{-1/2}`。

因此，固定大小的局部块、固定尺度的 block-glue 构造，在这些条件下不能成为统一扩张器。

它**没有**排除：

- 边长随 `m` 增长的非局部矩形；
- 改变速度点集合后的其他非局部构造；
- 改变规范化或其他明确假设后的模型。

### 为什么核维数 5 是精确的

每个证书都做了以下检查：

1. 所有行都是不重复的、规范化的整数弹性矩形行；
2. 五个整数不变量列都被所有行精确消掉；
3. 五个不变量在五个锚点上的评价矩阵行列式绝对值是 `2`，所以它们线性无关；
4. 证书列出一个阶数为 `N-5` 的整数子式，该子式的行列式模 `2` 等于 `1`，所以它在整数及有理数上非零。

因此精确得到 `rank_Q(C)=N-5`，有理核恰好是这五个不变量张成的空间。两个大素数秩计算只是独立筛查，不是有理秩证明的替代品。

但“有限矩阵的核恰好五维”**不能推出**“无限族有统一正谱隙”。

### 数值 gap 的复核

父级独立复核脚本直接从四份原始矩形行 JSON 重建 `C,D,A` 和加权约束空间，再进行新的约束特征值计算。四个 fresh gap 与表中值一致，fresh 算子残差都小于 `6×10^-10`，且没有求解器警告。

## 开放问题 `[O]`

仍未解决的自然网格版本是：是否存在绝对常数 `D<∞`、`c>0`，以及无穷增大的 `m`，可以在 `V_m` 上选择弹性矩形，使得

- 每个顶点度数在 `1` 与 `D` 之间；
- `ker_Q(C_m)` 恰好是五维碰撞不变量空间；
- 规范化谱隙 `γ_m>=c`；
- 允许矩形边长随 `m` 增长。

本文定理只说明：如果答案为正，这种构造不能一直局限在固定边长。它没有给出正构造，也没有证明所有非局部构造都失败。
